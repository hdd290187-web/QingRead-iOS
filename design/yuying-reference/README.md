# 历史品牌参考素材来源

这些品牌拼图、局部参考图及旧版 PNG 由项目用户上传。用户于 2026-11-13 在本次仓库公开审计的来源确认中说明：“是我自己生成的”。本说明记录该用户声明；结合用户已明确要求审计通过后公开现有仓库，历史 Git 与 Release 源码归档中的这些素材可以随本项目公开。

当前实际 App 图标采用 design/yuying-vector 中独立绘制的可编辑 SVG 及其导出 PNG；这些历史素材用于设计沿革与参考。原图没有作为 App 界面的全屏图片或背景预装。

本项目独立绘制的 SVG、绘制代码和无封面图案按仓库 MIT 许可提供；第三方字体、代码及出版物封面仍遵守各自许可与权利说明。
