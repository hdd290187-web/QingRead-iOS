# 予盈私人云书库原生接入

Build 45 在 Build 44 七项修复的 `36e8eed2fbdffd8cccfda6be76426a2346bc1945` 基础上开发，保留原 Bundle ID、图标、字体、四种 TXT 模式、EPUB、书架、阅读设置、书签和在线书源。云书库入口位于“发现 → 云书库”和“我的 → 云书库连接”，不新增底部标签。

地址固定为 `https://1.113188.xyz`，API v1 合约来自私人云仓库 `e99cf6f`。API 客户端实现书目分页、搜索、四种排序、TXT/EPUB 过滤、详情、有鉴权封面、原文件下载和 changes 双字段游标；当前界面采用完整下拉刷新对账，云端删除不会清理本地书。

只读设备令牌在 HTTPS 验证成功后写入 Keychain，使用 ThisDeviceOnly、不参与同步；不进入书库索引、UserDefaults、plist、URL、构建变量或应用日志。网络使用 ephemeral URLSession、关闭缓存/凭据和 Cookie 存储、拒绝重定向；封面也带 Authorization。401 要求重连，断开连接保留已下载小说。

下载在串行后台队列直接写入私人临时文件，限制文件长度、验证 ETag 与 SHA256 后才原子完成并调用原有导入队列。部分文件不含凭据，不保存可能包含请求头的 URLSession resumeData。续传严格检查 206 的 Content-Range；200 从零写入，416 清除无效部分，校验失败不入库。支持取消/重试；App 离开前台后利用 iOS 允许的后台执行时间继续，系统结束该时间时暂停，返回后可重试续传，不宣称可以无限期在后台运行。

云 UUID 通过可选 `Book.cloudLinks` 映射到现有本地 ID，并与原导入器的内容去重协同；旧索引无需重建。相同内容及改名不重复导入。更新须用户确认，新内容准备完成后原子写入索引，保留原 ID、同章节 ID、书签 ID；按章节、UTF16 位置及后台查找的正文锚点恢复，失败保留旧文件和索引。在阅读前预留书籍 ID，阻止更新覆盖正在使用的版本。

新增 CloudTests 及 CloudLibraryTests，覆盖合约、鉴权及错误、Keychain 生命周期、只存验证成功凭据、失效/离线、分页/changes、Range/200/416、散列、取消续传、TXT/EPUB 导入、快速重复点击、更新失败回滚、旧书库兼容和原生下载到书架/阅读器全流程。实际执行结果以最终 Actions 及交付 TEST_RESULT.txt 为准，Linux 语法解析不代替 iOS 编译或模拟器测试。

Release 校验要求新增云测试真实通过，并验证无 UI 测试模拟传输/启动参数进入 IPA。保留原 Xcode 与标准 macOS 工作流；Build 44 的旧构建结束前不修改 main 或 workflow。

云书库不提供进度同步、注册、上传、删除或设备管理。管理员在网页后台管理自己的藏书和设备令牌。真实 iPhone 使用原签名覆盖安装后的数据保留、手势流畅度和长时间后台下载仍需本人验收。
